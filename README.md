# Social Wall — Django REST API

A Python and Django-based social wall project that demonstrates web application development and RESTful API concepts.

## Overview

The project explores the development of a social-feed-style application and the use of a REST API to support communication between application components.

## Technologies

- **Backend:** Python, Django
- **API:** Django REST Framework (as identified for this project)
- **Web Technologies:** As implemented in the repository

## What This Project Demonstrates

- Django backend development
- REST API concepts and endpoint organization
- Request and response handling
- Structuring a Python web application
- Working with application data through backend components

## Getting Started

### Prerequisites

- Python 3.x
- pip
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/AmirMohammadNajafi1383/Wall_project_django.git
cd Wall_project_django
```

Create and activate a virtual environment:

```bash
python -m venv venv
```

macOS/Linux:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```

Install the dependencies using the repository's requirements file, if provided:

```bash
pip install -r requirements.txt
```

Apply database migrations:

```bash
python manage.py migrate
```

Run the development server:

```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
